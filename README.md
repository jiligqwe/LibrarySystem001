# LibrarySystem001
 基于Qt(C++)开发的简易图书管理系统
 ## 项目简介
 本项目为C++课程实训项目，使用Qt Creator开发桌面GUI程序，采用SQLite嵌入式数据库，实现图书馆基础业务管理。程序支持图书、读者信息维护与图书借阅归还流程，界面简洁，开箱即用，无需额外部署数据库服务。
 ## 技术栈
 - 开发语言：C++
 - GUI框架：Qt5
 - 数据库：SQLite
 - 开发工具：Qt Creator
 ## 功能模块
 1. 图书管理：图书信息新增、查询、修改、删除
 2. 读者管理：读者信息录入、检索、编辑
 3. 借阅业务：图书借阅、归还操作，自动保存借阅记录
 4. 信息检索：支持按书名、作者快速查询图书
 5. 数据持久化：全部信息保存在本地SQLite数据库文件
